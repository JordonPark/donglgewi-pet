# 동글귀

동글귀는 사진에서 찾아낸 아이템으로 돌보고 함께 논 추억을 기억하는 2.5D 로컬 AI 펫입니다. Android와 iOS에서 Apple Vision 또는 ML Kit로 사진을 분류하고, Kanana 모델을 받아 기기에서 대화할 수 있습니다.

## 첫 시연

1. **설정 → 시연 새로 시작 · 첫날 18시**를 엽니다.
2. **가방 → 아이템 얻기 → 시연용 소풍 장면**에서 사과와 원반을 담습니다. 방에서 **먹이기**로 사과를 주고, **공원 산책**으로 이동한 뒤 **원반 던지기**를 실행합니다.
3. 첫 원반을 던지기 전에 말풍선에서 **기다려**를 고르고 **던져줄게**를 누릅니다. 펫이 원반을 받아오면 행동을 배웁니다.
4. **설정 → 24시간 뒤 재방문**을 누른 뒤 **집으로** 돌아와 청소하고 먹이 두 개를 줍니다. 공원에 다시 가면 펫이 먼저 기다립니다.
5. **설정 → 48시간 뒤 · 셋째 날**을 누르고 집에서 돌본 다음 **성장 엔딩 보기 → 마지막 원반**을 고릅니다. **새 펫 키우기**로 다음 펫을 시작하면 방에 작은 원반이 남습니다.

**찾아봐 시연**은 첫날 사진 없이 기본 먹이를 준 뒤 공원에서 **산책하기 → 찾아봐**로 시작합니다. 단서가 가리킨 위치를 고르고, 24시간 뒤 같은 돌봄을 마쳐 다시 공원에 갑니다. 48시간 뒤에는 **우리가 찾은 솔방울**의 기념품을 새 펫의 방에서 눌러 공원 찾기 놀이로 이어갈 수 있습니다.

**레벨별 공간 시연**은 솔방울을 가방에서 **방에 두기**로 창가나 러그 옆에 놓습니다. 방에 다시 돌아오면 펫이 자리에 따라 별을 보거나 함께 앉자고 합니다. Lv. 3 공원에서는 펫이 낮은 돌 앞으로 갑니다. 반짝이는 돌을 눌러 나무 뒤를 탐색합니다. 애정도 5를 모은 뒤 **36시간 뒤 · 원반 착지점**에서 돌봄을 마치고 공원으로 가면 원반의 두 경로를 고를 수 있습니다. 가까운 잔디는 즉시 던지고, 벤치 너머는 펫의 준비 신호를 보고 **지금 던지기**를 누릅니다.

**15시간 뒤 재방문**은 첫날부터 따로 실행해 건강한 상태의 첫 인사를 확인할 수 있습니다.

웹은 기본 대사와 사진의 수동 아이템 선택을 지원합니다. 실제 모델 추론은 모바일 설정에서 Kanana 모델을 받은 후 사용할 수 있습니다. 모델은 약 1.52GB이며 앱 설치본과 별도로 다운로드합니다.

## 개발

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run -d chrome
```

Android 앱 ID와 iOS 번들 ID는 모두 `com.jordonpark.donglgewi`입니다. iOS 16.4 이상을 대상으로 합니다. GitHub Actions의 **Donglgewi TestFlight**에서 **Build a Shorebird release for TestFlight**와 **Upload**를 선택하면 내부 테스트용 OTA 기준 빌드를 올립니다. 이 빌드를 설치한 후에는 **Publish a patch to the exact internal release**에 `0.1.0+3`처럼 해당 버전과 빌드 번호를 입력해 Dart 변경을 배포할 수 있습니다. 앱을 실행하면 패치를 확인하며, 내려받은 패치는 다음 실행부터 적용됩니다. 전체 빌드에는 Apple 팀 변수와 App Store Connect 키가, OTA 릴리스 및 패치에는 `SHOREBIRD_TOKEN`이 필요합니다.

iPhone Duo를 펼치면 왼쪽에 장면, 오른쪽에 조작 영역을 표시합니다. 접힌 화면에서는 iOS 네이티브 툴바에서 가방·앨범·도감·설정을 열고, 방에서 먹이기·청소하기, 공원에서 원반 던지기·산책하기·벤치에서 쉬기를 장면 아래에서 시작합니다. 화면 크기와 안전 영역이 바뀌어도 작성 중인 대화가 유지됩니다. 새 iOS 빌드는 iOS 27.1 SDK 이상을 사용합니다.
